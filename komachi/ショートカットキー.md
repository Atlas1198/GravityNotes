# ショートカットキー一覧

## システム（main.cpp）

| キー | 動作 |
|---|---|
| Alt + Enter | フルスクリーン切り替え |
| F11 | フルスクリーン切り替え |

---

## ゲームシーン

### デバッグ操作（game.cpp / debug_ui.cpp）

| キー | 動作 |
|---|---|
| F1 | DebugUI ウィンドウ トグル |
| F2 | マウスカーソル表示 |
| F3 | マウスカーソル非表示 |
| F4 | カメラ切り替え |

### カメラ移動（gamecamera.cpp） ※現在はデバッグ用フライカメラ

| キー | 動作 |
|---|---|
| W / A / S / D | 前後左右移動 |
| Space | 上昇 |
| Shift | 下降 |
| Escape | タイトルシーンへ遷移 |

### プレイヤー操作（player.cpp）

| キー | 動作 |
|---|---|
| A / D | レーン左右移動（床・天井面） |
| W / S | レーン移動（左右壁面） |

> **注意：** W/A/S/D は gamecamera.cpp とプレイヤー操作で競合している。GameCamera を本実装に差し替える際に整理が必要。

---

## デバッグシーン

### シーン共通（debugscene.cpp）

| キー | 動作 |
|---|---|
| Tab | デバッグシーン切り替え |

### デバッグカメラ（debugcamera.cpp）

| キー | 動作 |
|---|---|
| W / A / S / D | 前後左右移動 |
| Space | 上昇 |
| Shift | 下降 |
| Escape | タイトルシーンへ遷移 |

### モデルデバッグシーン（debug_model_scene.cpp）

| キー | 動作 |
|---|---|
| 1〜0 / Numpad1〜0 | アニメーション選択 |
| B | ボーン表示切り替え |
| R | アニメーションリセット |

### スコアデバッグシーン（debugscore.cpp）

| キー | 動作 |
|---|---|
| F1 | ポーズ トグル |
| F / G / H / J | レーン1〜4 ヒット判定 |
| Escape | タイトルシーンへ遷移 |

---

## input_manager（framework/input_manager.cpp）

| キー | 動作 |
|---|---|
| Enter / Space | 決定 |
| Escape / Backspace | キャンセル |
| 上下左右矢印 | UI カーソル移動 |
| P | ポーズ |
